蜂窝 Windows 找回窗口工具

适用于：任务管理器存在蜂窝加速器进程，但屏幕上找不到界面。

1. 解压整个 ZIP，保留所有文件在同一文件夹。
2. 保持蜂窝进程运行，双击 Recover-FengWo-Window.cmd。
3. 等待约 10 秒，确认蜂窝界面是否出现。
4. 如果未出现，把工具提示的 FengWo-Window-Report 压缩包发回客服。
   默认保存在桌面；桌面不可写时使用临时目录，窗口会显示准确位置。

若蜂窝已用管理员身份启动、普通运行此工具未恢复窗口，可右键上述 CMD，选择“以管理员身份运行”后重试一次。

工具只处理当前 Windows 登录会话中 FengWo.exe 的 Flutter 主窗口，将窗口恢复并移至 Windows 指定的主显示器工作区。
不会结束蜂窝或代理核心进程，不读取账号密码、订阅或配置内容，不修改系统代理、注册表或配置文件，不自动上传报告。
移动和调整窗口大小可能由蜂窝自身记住，之后可正常拖动或缩放。

报告记录显示器名称、位置与工作区，蜂窝进程编号、权限级别、窗口位置、是否隐藏或最小化、响应状态，以及移动前后的结果。
“窗口位于主屏范围内”是窗口状态检查结果，不能证明 Flutter 画面已正确绘制；仍需用户确认能看到界面。
此工具用于恢复界面和定位问题，不代表客户端永久修复版本。
