incident logs; the real Windows controlled reproduction and compatibility
repair passed, but the original customer root cause remains unconfirmed.

failure; the same client and machine pass through the working Singapore node.
No certificate validation was disabled. Separate ARM64 physical-machine network
acceptance was waived by the user; native ARM64 CI validation passed.

No live installer, mirror file, download URL, fixed filename or configuration
has been replaced. A source push is not authorization to publish. No release
tag or production deployment is part of this submission.
