## 实现与修复

- Linux CI 在打包前执行根包分析和全量测试、Go 包装层测试/分析、Linux Helper、托盘和 build_tool 测试。
- 打包校验 DEB 架构和 app/Core/Helper 的 x64 ELF，以及安装 manifest 与 Core SHA256 一致性；随包提供说明、校验文件和预检脚本。
- Ubuntu runner 实际安装、覆盖安装、移除软件包，并运行已安装的 systemd Helper：校验哈希、会话隔离、Core IPC、停止和服务退出时的子进程回收。
- Ubuntu 和 Debian 均在非 root、Xvfb/Openbox/D-Bus 会话下启动已安装 GUI，检查窗口和重复启动唤醒并保存截图、日志。
- Debian 12 容器使用同一构建产物验证动态库依赖、安装、启动、重复启动与移除；不伪装成完整 systemd 桌面验收。
- 修复原 connectivity_plus Linux 订阅初始化在缺少 NetworkManager 时产生的未捕获异步异常。Linux 独立管理 NetworkManager 客户端，失败时降级为每五秒检测网卡；取消订阅立即停止轮询。
- 修复 dbus 0.7.14 在系统总线 socket 不存在时，信号订阅内部 Future 绕过外层捕获的问题：先完成总线方法调用，再建立 NetworkManager 订阅；新增真实缺失 Unix socket 回归测试。
- 无 NetworkManager 或系统总线时不强制安装服务，不将查询失败伪造为断网；过滤容器桥接、回环和已知 VPN 接口，保持物理网络语义。
- Core 日志订阅仅在 Core 已连接后同步，重连时重新应用，避免登录页面挂载时向尚未启动的 Core 发送 stopLog 并超时。
- 遵守 `core-platform` 与 `provider-tests` 规范：不新增 Core 进程管理者，不修改终态关闭语义，测试直接覆盖 provider 默认断开状态与连接后的日志行为。

## 人工验收边界

安装包为测试版本。以下必须在真实 Ubuntu / Debian 桌面继续验收：

- 真实账号登录、订阅更新、节点连接、工单与业务服务交互。
- 系统代理的启停和实际流量；TUN 路由、DNS 与断开后恢复。
- polkit 交互授权、取消授权、重启机器后的 Helper 行为，以及 Debian 真实 systemd 服务。
- GNOME/KDE 托盘、Wayland、深链、关闭/退出窗口、休眠恢复、物理网络切换、运行中网络服务重启和多用户桌面。

CI 未接受首启免责声明、未输入账号、未创建订单或支付、未配置实际 TUN 流量。不能把无头启动与 Helper IPC 通过表述为全部业务和网络场景通过。
