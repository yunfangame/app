## Windows 兼容性核验

实际锁定版本中，`WindowsOptions.useBackwardCompatibility` 默认是 `false`；已与官方 v10.3.1 源码核对。因此没有按“旧凭据清理失败一定是根因”的未经证实假设修改 Windows 选项，也没有关闭既有迁移或降级为明文存储。[官方选项源码](https://raw.githubusercontent.com/juliansteenbakker/flutter_secure_storage/v10.3.1/flutter_secure_storage/lib/options/windows_options.dart)

另记录底层 SDK 风险：Windows 4.2.2 的 DPAPI 加载实现会在解密或 JSON 格式异常后删除损坏文件；写入路径对文件系统异常持续重试。本次没有改动依赖源码，客户现有日志也未证明触发这些路径。需要 Windows 原生发布包验收，不能承诺共享 Dart 修复覆盖全部底层行为。[官方 Windows 实现](https://raw.githubusercontent.com/juliansteenbakker/flutter_secure_storage/flutter_secure_storage_windows-v4.2.2/flutter_secure_storage_windows/lib/src/flutter_secure_storage_windows_ffi.dart)
