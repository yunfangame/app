蜂窝客户端 Windows 启动诊断

适用：可以安装，但点击后没有窗口、闪退、只在后台运行或被系统拦截。

1. 把整个 ZIP 解压到桌面，不要在压缩包内直接运行。
2. 在出问题的 Windows 登录用户下，双击 Collect-Startup-Diagnostics.cmd。
   首次请正常双击，不要改成“以管理员身份运行”，以便复现原用户的问题。
3. 工具通常自动找到客户端。若检测到多个安装位置，选择出问题的那一个；
   若没有找到，把桌面客户端快捷方式或安装目录内的 FengWo.exe 拖进窗口并回车。
4. 工具会尝试启动一次客户端并显示“开始观察”，默认观察 60 秒。
   期间请保留错误弹窗，不要重复启动、关闭或卸载客户端。总耗时通常数分钟。
5. 看到“诊断完成 / Finished”后，把桌面新生成的
   FengWo-Windows-Startup-Report-日期时间-随机字符.zip 发回客服。
   若桌面不可写，窗口会显示报告保存的临时目录。

采集内容：实际安装版本、签名、文件完整性、PE 架构与静态依赖；启动前后进程与窗口、
退出码；运行库、显卡驱动、数据目录权限、配置文件有效性；程序崩溃和系统拦截记录。
部分日志没有权限时会保留其他结果，不会让整个报告作废。

采集器不会自动修复，不会结束客户端进程、修改系统代理、防护、权限或注册表。
启动客户端本身可能执行客户端原有的配置恢复、登录和自动连接流程。
报告不自动上传，不包含密码、订阅配置原文、数据库内容或内存转储。
结构化客户端诊断日志会脱敏；系统记录仍包含排查需要的设备与安装路径信息。

如果黑窗口一闪而过或 PowerShell 被企业策略拦截，请在命令提示符里打开本目录，执行：
Collect-Startup-Diagnostics.cmd
把显示的具体错误发回客服，不需要关闭企业防护或修改系统策略。

仅采集当前状态、不尝试启动客户端：
Collect-Startup-Diagnostics.cmd -NoLaunch

指定客户端路径：
Collect-Startup-Diagnostics.cmd -AppPath "D:\FengWo\FengWo.exe"
