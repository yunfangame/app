蜂窝 Windows 系统代理诊断工具

适用：Windows x64 / ARM64，W-PROXY-04 (13)、手动打开系统代理后自行关闭等问题。
本工具不是新客户端。不要卸载、覆盖原客户端，不需要账号、密码或订阅链接。
完整解压 ZIP。不要在压缩包内部直接运行。

一、重点：检测“谁关闭了电脑网络设置中的代理”
1. 保持蜂窝和网络故障现场；不要提前关闭其他程序或更换网络。
2. 右键 Trace-Who-Changed-Proxy.cmd，选择“以管理员身份运行”，确认系统授权。
3. 必须是运行蜂窝的同一个 Windows 用户；不要用另一位管理员账户代跑。
4. 输入 TRACE，看到“监控开始”后，再打开 Windows 设置中的手动代理。
5. 等待它自行关闭。45 秒后工具结束监控并生成报告 ZIP。
6. 把报告 ZIP、这次蜂窝导出的日志一起回传，并说明开关大约何时关闭。
7. 若没捕获到关闭，重新运行再复现一次；不能凭空推断关闭者。

追踪会短暂启用本工具自己的 ETW 会话，采集注册表写入/进程事件。
追踪期间只读注册表采样，不调用 WinINet 查询、刷新或联网探测，避免采样触发 Windows 重新同步不一致的代理配置。
它不修改审核策略、不改代理、DNS、TUN、路由，也不关闭其他程序。
会话有时间和大小限制。结束后停止会话，将原始 ETL 留在本机私有目录并加密，不放入回传 ZIP。
公开报告只保留代理项名称、写入时间、PID、可解析的进程文件名、系统状态码，以及捕获到的 ProxyEnable 启停布尔值，不输出原始路径、用户名、代理密码或其他注册表值内容。
报告把代理关闭窗口与写入进程对照，列为候选证据，不把时间接近直接说成已确认因果。
Windows 服务可能代替其他程序写入；没有捕获到进程、事件丢失或无法解析时会明确标注未确定。
如果系统策略不允许追踪，请联系公司管理员；不要停用安全软件、组策略或证书校验。

二、普通检测和只读监控
双击 Start-Proxy-Diagnostics.cmd：
1 = 只读检测（默认）
2 = 监控开关变化 45 秒，但不定位写入进程
3 = 引导测试连接、断开和托盘退出
4 = 刷新修复
5 = 进程级追踪（仍需同用户管理员权限及 TRACE 确认）
只读检测通常不需要管理员权限。
工具读取 Unicode/ANSI WinINet、当前用户/机器代理项、相关策略、已知代理进程、浏览器策略及网卡类型。
虚拟网卡只标记为可能的 TUN 通道，网卡存在不代表当前流量一定经过它。
有线网络和手机热点请分别运行并标记，不要在一次监控过程中切换。
网线本身不等于故障原因；自动代理发现、公司策略、PAC、TUN 或浏览器代理都需要证据。

三、刷新修复
先完全退出蜂窝和其他代理客户端，再选 4、输入 REFRESH 确认。
先保存仅当前 Windows 用户可解密的本机备份，再刷新 Windows 代理缓存/通知。
发现策略、读取不一致、客户端未退出或状态变化时，会拒绝或停止刷新。
不会重写代理地址、禁用/清空 PAC、修改组策略、执行网络重置或强制回滚其他软件的新设置。
刷新不保证修好写入兼容、系统策略或第三方干预问题，不能以“刷新完成”作为验收通过。
本工具不写代理配置，不会用备份强制覆盖系统设置；如检测到外部变化，保留现场供排查。

四、连接、断开和退出验收
选 3 后按提示：断开并记录初始状态，连接并记录，断开并记录，再连接后从托盘退出并记录。
若有错误弹窗，保留现场，不要连续点击重试。不要只关闭窗口 X。
工具不会自动点击客户端或强制结束进程，不修改节点和模式设置。
通过标准包括系统代理正确接管、断开恢复初始配置、退出后进程退出且代理恢复。
记录当前 TUN 状态，不要为了检测强行改变 TUN；本工具不验收 TUN 清理。
原来有公司 PAC 时，恢复初始配置不等于完全直连。
系统代理开关关闭、但网站能打开，也可能是 PAC、TUN、浏览器独立代理等通道在工作。
联网探测只对百度和微软首页做 HTTPS HEAD 对照，不保存正文，不发送 Cookie 或账号凭据。
“不使用显式 HTTP 代理”不能绕过 TUN；HTTP 状态也不能证明所有应用的出口或加速是否生效。

五、日志回传
每次结束打印 FengWo-Proxy-Report-日期时间.zip 的完整位置。
默认位置：%LOCALAPPDATA%\FengWoProxyDiagnostics\ 对应日期文件夹。
只发这个报告 ZIP，另附蜂窝本次导出日志、网线或热点的说明，以及实际联网表现。
报告对代理地址、PAC 和排除域名只保留随机盐哈希、长度、状态，不输出原文。
不要发送 private 目录、private-backup.dpapi、原始 ETL、账号密码或整个客户端数据目录。
工具不会自动上传任何日志。刷新、检测、追踪都不会替换原客户端或线上配置。
启动器的 ExecutionPolicy Bypass 只作用于当前检测进程，不修改整机执行策略。
