蜂窝 Windows 关机／卡死日志采集（第二版）

1. 解压整个压缩包。
2. 双击 Collect-Diagnostics.cmd，等待显示 Finished。
3. 桌面会生成 FengWo-Windows-Diagnostics-日期时间.zip，把这个新生成的文件发给客服。

无需打开蜂窝客户端，也无需再次点击连接或系统代理。

工具只读取最近 24 小时的完整系统事件、应用崩溃／卡死记录、Windows 版本、启动时间、网卡与运行中的驱动信息、崩溃转储设置、分页文件状态和转储文件清单。
不会修改系统代理、网络、驱动或电源设置，不会自动上传文件，也不会收集账号配置或转储文件内容。

如果窗口提示 Collection failed，请把该窗口截图发给客服。
如果部分记录无法读取，其余记录仍会打包，失败原因保存在 collection-errors.txt。
